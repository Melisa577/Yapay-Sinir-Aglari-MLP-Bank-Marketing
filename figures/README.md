# Grafikler ve Görselleştirmeler

Aşağıdaki SVG grafikleri, kaydedilmiş model değerlendirme sonuçları kullanılarak yeniden oluşturulmuştur:

- **`outer_method_AP.svg`:** Dummy, Logistic Regression, manuel arama ve rastgele arama yöntemlerinin dış çapraz doğrulamadaki ortalama AP değerlerini göstermektedir.
- **`test_model_AP.svg`:** Üç farklı seed ile eğitilen MLP modellerinin ve Logistic Regression modelinin bağımsız test kümesindeki AP değerlerini göstermektedir.
- **`mlp_confusion.svg`:** MLP modeline ait karmaşıklık matrisi sonuçlarını göstermektedir (TN=719, FP=15, FN=68, TP=22).
- **`logistic_confusion.svg`:** Logistic Regression modeline ait karmaşıklık matrisi sonuçlarını göstermektedir (TN=722, FP=12, FN=72, TP=18).
