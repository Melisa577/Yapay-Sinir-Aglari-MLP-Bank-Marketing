# Hiperparametre Yapılandırmaları

Bu klasör, MLP modelinin hiperparametre optimizasyonunda kullanılan yapılandırmaları içermektedir.

Çalışmada, **M1–M6** olmak üzere altı manuel ve **R1–R6** olmak üzere altı rastgele hiperparametre adayı değerlendirilmiştir.

Bu yapılandırmalar `candidates.json` dosyasında saklanmaktadır.

Dosya, deneylerde kullanılan hiperparametre seçeneklerinin incelenmesine ve model karşılaştırmalarının tekrarlanmasına yardımcı olmaktadır.
