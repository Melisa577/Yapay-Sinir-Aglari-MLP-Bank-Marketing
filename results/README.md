# Deney Sonuçları

Bu klasör, Google Colab ortamında gerçekleştirilen deneylerden elde edilen CSV ve JSON dosyalarını içermektedir.

Veri kümesi ayrımları, hiperparametre arama sonuçları, çapraz doğrulama çıktıları, model eğitim kayıtları ve bağımsız test tahminleri bu klasörde saklanmaktadır.

Tekrarlanabilirliğin sağlanması amacıyla deney çıktıları korunmuş ve test tahminlerinin kilitlenmesine ilişkin GitHub commit geçmişinin kontrol edilmesi gerektiği belirtilmiştir.
